Personal Health Sync

A personal, single-user tool for reading my own Google Health data.
个人自用的 Google 健康数据读取工具（仅本人使用）。

What this application does / 本应用做什么

Personal Health Sync is a private, self-hosted script that I run on my own computer. It connects to the Google Health API with my explicit consent and retrieves my own health data (steps, distance, activity minutes, sleep, heart rate, blood glucose, weight, body fat, energy, heart-rate variability, resting heart rate, oxygen saturation and respiratory rate) so that it can be summarised into a personal daily health report for me.

本应用是一个运行在我自己电脑上的私人脚本。经我本人明确授权后，它通过 Google 健康接口（Google Health API）读取我本人的健康数据（步数、距离、活动时长、睡眠、心率、血糖、体重、体脂、能量消耗、心率变异性、静息心率、血氧、呼吸率），并据此为我生成个人每日健康报告。本应用不面向公众提供任何服务。

Key facts / 要点

  • Single user (the owner). No accounts are created for anyone else. / 仅服务一个用户（即本人），不为他人开设账号。
  • Data is stored locally on the owner's own computer. / 数据仅保存在本人自己的电脑本地。
  • No advertising, no analytics, no data selling. / 无广告、无数据统计、不售卖数据。
  • Access can be revoked at any time in the Google Account permissions page. / 可随时在谷歌账号的权限页面撤销授权。
