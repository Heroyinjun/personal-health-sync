Privacy Policy / 隐私政策

Personal Health Sync · Last updated: 2026-10-08

1. Who we are / 关于本应用

Personal Health Sync ("the Application") is a private, single-user tool operated by its owner for personal, non-commercial use. It is not offered to the general public and does not create accounts for third parties.
本应用（Personal Health Sync）是由其所有者自行运行、仅供个人非商业使用的私人工具，不向公众提供服务，也不为第三方开设账号。

2. What data is accessed / 访问哪些数据

With the owner's explicit OAuth consent, the Application reads the owner's own Google Health data through the Google Health API, limited to the following scopes:
经所有者本人通过 OAuth 明确授权后，本应用通过 Google 健康接口读取所有者本人的健康数据，权限范围仅限以下四类：

  • Activity and fitness (steps, distance, activity minutes, energy burned) / 活动与健身（步数、距离、活动时长、能量消耗）
  • Health metrics and measurements (heart rate, blood glucose, weight, body fat, heart-rate variability, resting heart rate, oxygen saturation, respiratory rate) / 健康指标与测量（心率、血糖、体重、体脂、心率变异性、静息心率、血氧、呼吸率）
  • Sleep / 睡眠
  • Basic profile information needed to identify the authorised account / 用于识别被授权账号的基本个人资料

3. How the data is used / 数据如何使用

The data is used solely to generate a private daily health summary and next-day suggestions for the owner. No automated decision-making with legal effect is performed, and no data is used for advertising, profiling, or resale.
数据仅用于为所有者生成私人每日健康小结与次日建议。不进行任何具有法律效力的自动化决策，也不用于广告、用户画像或转售。

4. Where the data is stored / 数据存储在哪里

All retrieved data is stored only on the owner's own personal computer, in a local folder controlled by the owner. It is not uploaded to any third-party server, cloud service, or shared drive.
所有取回的数据仅保存在所有者本人的个人电脑本地文件夹中，不上传至任何第三方服务器、云服务或共享网盘。

5. Sharing / 数据共享

No data is shared, sold, rented, or transferred to any third party. The Application contains no advertising, analytics, or tracking components.
数据不会向任何第三方共享、出售、出租或转让。本应用不含任何广告、统计或追踪组件。

6. Security / 安全措施

Access tokens and refresh tokens are stored locally on the owner's computer with file permissions restricted to the owner's user account. Access is limited to the owner's own Google Account.
访问令牌与刷新令牌仅保存在所有者电脑本地，且文件权限仅限所有者本人账号读写。数据访问仅限于所有者本人的谷歌账号。

7. Retention and deletion / 保留与删除

Data is retained locally only as long as the owner chooses. The owner may delete any local data files at any time. The owner may also revoke the Application's access at any time via the Google Account permissions page (myaccount.google.com/permissions); once access is revoked, the Application can no longer retrieve any data.
数据仅在所有者自行决定的时间内保存在本地，所有者可随时删除本地数据文件；也可随时通过谷歌账号权限页面撤销本应用授权，撤销后本应用即无法再读取任何数据。

8. Children's privacy / 未成年人隐私

The Application is not directed to children and is used only by its adult owner.
本应用不面向未成年人，仅由其成年所有者本人使用。

9. Changes to this policy / 政策变更

Any changes to this policy will be published on this page with an updated revision date.
本政策的任何变更都会在本页面发布并更新修订日期。

10. Contact / 联系方式

For any questions about this privacy policy, contact: heroyinjun@gmail.com
如对本隐私政策有任何疑问，请联系：heroyinjun@gmail.com

This Application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
本应用对来自谷歌接口的信息的使用，遵循《Google API 服务用户数据政策》，包括其中的"有限使用"要求。
